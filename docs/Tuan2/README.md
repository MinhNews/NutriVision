## 👥 Phân công công việc Tuần 2

* **TV3 (UI/UX Lead):** 
  * Mở file `03_Dac_ta_Wireframe_Figma.md` và `01_Design_System_va_UI_Guide.md`.
  * Tạo project trên Figma, vẽ 9 màn hình theo đúng quy chuẩn màu và font.
  * Lấy link chia sẻ Figma chèn vào báo cáo.
* **TV1 (Android Lead):**
  * Đọc file `04_Huong_dan_Dung_Layout_Compose.md`.
  * Khởi tạo project trong Android Studio, cấu hình file `Color.kt` và `Theme.kt`.
  * Dựng layout tĩnh 2 màn hình quan trọng nhất: `DashboardScreen.kt` và `MealCustomizerScreen.kt`.
* **TV2 (Data & Backend):**
  * Hỗ trợ TV1 kiểm tra preview trên Android Studio.
  * Tiếp tục tổng hợp dữ liệu dinh dưỡng và danh mục topping để chuẩn bị cho phần Database ở Tuần 3.
